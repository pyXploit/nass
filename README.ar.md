# نص · nass

**معالجة النص العربي كما ينبغي، في كل مكان يلمسه بايثون.**

[English](README.md)

تتعامل مكتبة بايثون القياسية مع العربية كسلسلة من نقاط الترميز. هذا صحيح
تقنياً، ونادراً ما يكون ما تريده: للكلمة الواحدة عدة إملاءات، وللأعداد ست صيغ
جمع، والمحرك الذي لا يشكّل الحروف يحوّل نصك إلى أشكال منفصلة بترتيب معكوس.

`nass` هي الطبقة بين هذين الأمرين. كل دالة تأخذ نصاً عربياً وتعيد نصاً عربياً —
بلا كائنات، بلا إعدادات، بلا مفاجآت.

## التثبيت

```bash
pip install git+https://github.com/pyXploit/nass
```

لم يُنشر على PyPI بعد — سيحدث ذلك مع إصدار `0.2.0`.

## أمثلة

```python
import nass

nass.normalize("أَحْمَد")             # 'احمد'
nass.words(1234)                     # 'ألف ومئتان وأربعة وثلاثون'
nass.count(3, "كتاب", plural="كتب")  # '٣ كتب'
nass.ordinal(21)                     # 'الحادي والعشرون'
nass.plural_category(11)             # 'many'
nass.to_arabic_digits("2026")        # '٢٠٢٦'
nass.shape("بب")                     # '\ufe91\ufe90'
nass.display("بب")                   # '\ufe90\ufe91'
nass.wrap(text, 320, measure=font.getlength)
```

## صيغ الجمع

للعربية ست صيغ جمع، ولكل صيغة شكل مختلف للاسم:

| العدد | الصيغة | المثال |
|---|---|---|
| ٠ | zero | صفر كتاب |
| ١ | one | كتاب |
| ٢ | two | كتابان |
| ٣–١٠ | few | ٣ كتب |
| ١١–٩٩ | many | ١١ كتابًا |
| ١٠٠+ | other | ١٠٠ كتاب |

## التطبيع

| المدخل | المخرج | القاعدة |
|---|---|---|
| أحمد | احمد | الألف |
| مدرسة | مدرسه | التاء المربوطة |
| مصطفى | مصطفي | الألف المقصورة |
| كـتـاب | كتاب | التطويل |
| مُحَمَّد | محمد | التشكيل |
| ١٢٣ | 123 | الأرقام الهندية |

كل قاعدة يمكن تعطيلها عند الحاجة إلى الحفاظ على الإملاء الأصلي:

```python
nass.normalize("مُحَمَّد", strip_diacritics=False)  # 'مُحَمَّد'
```

## التشكيل

تتغير أشكال الحروف العربية حسب ما يجاورها. المحرك الذي يرسم محرفاً واحداً لكل
نقطة ترميز — مثل matplotlib وPIL ومعظم مكتبات PDF — يعرضها منفصلة وبترتيب
معكوس.

```python
nass.shape("بب")    # '\ufe91\ufe90'  أولي + نهائي
nass.display("بب")  # '\ufe90\ufe91'  تشكيل ثم إعادة ترتيب
```

`shape()` يحافظ على الترتيب المنطقي، لمن يتعامل مع الاتجاه بنفسه.
`display()` يعيد الترتيب أيضاً، لمن لا يفعل.

## تقسيم الأسطر

```python
nass.wrap(text, 320, measure=font.getlength)
```

`measure` يحوّل النص إلى عرضه المرسوم — مرّر دالة محركك. القيمة الافتراضية
`len` مناسبة للنصوص أحادية العرض فقط. تبقى علامات الترقيم العربية مع الكلمة
التي تسبقها، فلا يبدأ سطر بفاصلة.
