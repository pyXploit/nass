# API reference

Every function takes and returns `str` unless stated otherwise. Nothing raises on
ordinary input: a word the lexicon does not know returns `None` (or `[]`) rather
than a guess.

```bash
pip install nass
```

```python
import nass
from nass import inflect
```

`nass` re-exports the inflection functions, so `nass.plural` and
`inflect.plural` are the same object.

## Conventions

**`vocalized`.** The inflection functions take `vocalized=False` by default and
return the bare spelling. `vocalized=True` returns the diacritized form.

```python
>>> inflect.plural("كتاب")
'كتب'
>>> inflect.plural("كتاب", vocalized=True)
'كُتُب'

```

**`None` means unknown, not empty.** `plural("زززز")` is `None` because the word
is not in the lexicon. `plural("موز")` is also `None`, but `known("موز")` is
`True`: the word is a collective with no distinct plural. Use `known` to tell the
two apart.

**The definite article is stripped on lookup**, so `plural("الكتاب")` works. A
short blocklist keeps lexicalised words such as `الأولى` and `اللهم` from being
read as article + stem.

## Text normalisation

### `normalize(text, *, strip_diacritics=True, unify_alef=True, unify_teh_marbuta=True, unify_yeh=True, strip_tatweel=True, unify_digits=True) -> str`

Folds text to a canonical form for comparison. Every rule can be switched off.

```python
>>> nass.normalize("أَكْتُبُ")
'اكتب'
>>> nass.normalize("أَكْتُبُ", strip_diacritics=False)
'اَكْتُبُ'

```

### `remove_diacritics(text) -> str`

Drops every combining mark, including tatweel.

```python
>>> nass.remove_diacritics("كِتَابٌ")
'كتاب'

```

### `is_arabic(text, threshold=0.5) -> bool`

True when at least `threshold` of the letters are Arabic script. Punctuation and
digits are ignored, so mixed strings can pass.

```python
>>> nass.is_arabic("مرحبا")
True
>>> nass.is_arabic("hello مرحبا")
True

```

### `collapse_whitespace(text) -> str`

Collapses runs of whitespace to one space and trims the ends.

```python
>>> nass.collapse_whitespace("  أهلا   وسهلا  ")
'أهلا وسهلا'

```

## Numbers

### `words(n) -> str`

Spells an integer in Arabic words, applying the dual where Arabic requires it.

```python
>>> nass.words(5)
'خمسة'
>>> nass.words(2026)
'ألفان وستة وعشرون'

```

### `count(n, singular, *, dual=None, plural=None, accusative=None, arabic_digits=True) -> str`

A number with a correctly inflected noun. Supply the forms you have; the function
picks the right one for the count.

```python
>>> nass.count(3, "كتاب", plural="كتب")
'٣ كتب'
>>> nass.count(2, "كتاب", dual="كتابان")
'كتابان'

```

### `ordinal(n) -> str`

1–99 as an ordinal word.

```python
>>> nass.ordinal(3)
'الثالث'

```

### `plural_category(n) -> str`

The CLDR plural category: `zero`, `one`, `two`, `few`, `many` or `other`.

```python
>>> [nass.plural_category(n) for n in (0, 1, 2, 3, 11, 100)]
['zero', 'one', 'two', 'few', 'many', 'other']

```

### `to_arabic_digits(text) -> str` · `to_western_digits(text) -> str`

Convert between Arabic-Indic and Western digits, leaving everything else alone.

```python
>>> nass.to_arabic_digits("2026")
'٢٠٢٦'
>>> nass.to_western_digits("٢٠٢٦")
'2026'

```

## Inflection

Sourced from a lexicon of 19,298 lemmas built out of English Wiktionary and
arramooz. Nothing is generated by rule: a form is returned only when a dictionary
attests it.

### `plural(word, *, vocalized=False) -> str | None`

The primary plural, or `None`.

```python
>>> inflect.plural("كتاب")
'كتب'

```

### `plurals(word, *, vocalized=False) -> list[str]`

Every attested plural, primary first. Empty when the word is unknown or has none.

```python
>>> inflect.plurals("مدرسة")
['مدرسات', 'مدارس']

```

### `dual(word, *, vocalized=False) -> str | None` · `duals(word, *, vocalized=False) -> list[str]`

The dual, singular and plural forms respectively.

```python
>>> inflect.dual("كتاب")
'كتابان'
>>> inflect.duals("كتاب")
['كتابان']

```

### `glosses(word) -> list[str]`

Short English glosses, so homographs can be told apart.

```python
>>> inflect.glosses("عين")[0]
'eye (organ)'

```

### `known(word) -> bool`

Whether the word has a lexicon entry at all.

```python
>>> inflect.known("كتاب")
True
>>> inflect.known("زززز")
False

```

## Shaping

### `shape(text) -> str`

Maps letters to their Arabic Presentation Forms, keeping logical order. Useful
when a renderer does not shape Arabic itself.

```python
>>> nass.shape("كتب")
'ﻛﺘﺐ'

```

### `display(text) -> str`

Shaped and reordered for a left-to-right renderer that does no bidi of its own.

```python
>>> nass.display("كتب")
'ﺐﺘﻛ'

```

## Layout

### `wrap(text, width, *, measure=len, break_long_words=False) -> list[str]`

Breaks text into lines that respect Arabic punctuation. `measure` is any callable
mapping a string to a width, so pixel measurement works as well as character
counts.

```python
>>> nass.wrap("هذا نص عربي طويل نريد كسره إلى أسطر", 20)
['هذا نص عربي طويل', 'نريد كسره إلى أسطر']

```

## Speech

### `speak(text, *, months="levantine") -> str`

Reads numbers, times, dates and percentages aloud. `months` selects the month-name
set: `levantine` or `egyptian`.

```python
>>> nass.speak("3/4/2026")
'الثالث من نيسان عام ألفان وستة وعشرون'
>>> nass.speak("5%")
'خمسة بالمئة'
>>> nass.speak("9:45")
'العاشرة إلا ربعاً'

```

## matplotlib

### `plot.enable()` · `plot.disable()` · `plot.shapes_natively()`

matplotlib 3.11 and newer shape Arabic through HarfBuzz, so `enable()` is a no-op
there and returns `False`. On older versions it patches the text pipeline and
returns `True`. `shapes_natively()` reports which case you are in.

matplotlib is an optional dependency: importing `nass` does not import it, and
`plot` raises only when you call it without matplotlib installed.

## Known limitations

- **One register.** The lexicon records MSA forms. Levantine colloquial plurals
  are not distinguished, so `count(3, "كتاب")` gives the MSA `ثلاثة كتب` and not
  the Levantine `ثلاث كتب`. A register switch is not implemented.
- **No case endings.** Forms are stored undiacritized by default; `vocalized=True`
  returns the dictionary's own vocalization, which is not a case-inflected form.
- **Coverage is not total.** 18,639 of 19,298 lemmas have a plural. A word outside
  the lexicon returns `None`; it is never guessed.
- **Broken plurals are lexical.** They cannot be derived by rule — `مدرسة` gives
  `مدارس` but `سيارة` gives `سيارات` — which is why the lexicon exists at all.
